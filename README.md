# Robô Virtual — Tapete de Missões

Simulador de programação em blocos: o estudante monta o programa e um robô virtual percorre o tapete de missões (1 quadrante = 10 cm), usando os sensores de cor e de obstáculo.

Feito por Pedro Lima, Orientador Educacional.

- `index.html` — o app completo em um único arquivo; abre em qualquer navegador.
- `fonte/` — código-fonte (blocos, simulador, página e script de montagem).

O editor de blocos usa o [Blockly](https://github.com/google/blockly) (Apache-2.0).
